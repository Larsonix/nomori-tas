Nomori TAS — cheat sheet

Keys work in Studio (cursor on an input line, not a # line) and in the game window. 60 frames ≈ 1 second.

Keys

F1New run from New Game. While a TAS plays: stop it. That frame is the start for search points
F2New run, always
F3Pause / resume
F4One frame forward. Hold to repeat
F5One frame back. Hold to repeat
F6 holdFast-forward
F7 holdSlow motion
F8 / F9Remember this frame / forget it
F10Fast-forward to the next #comment
F11Search. Shift+F11 checkpoint, Ctrl+F11 clear them
F12Live recording on / off. Also leaves frame by frame
²Frame by frame with your own keys (game window). ² or F12 leaves
Shift+1…0Keep this frame in a slot (top row, game window). The key alone goes back to it
H / Shift+HHitboxes / what they show (game window)
LLaser from the character's head (game window)

At the end of the file the TAS pauses on its last frame. F3 gives you the game back.

Buttons in a line

JAJump
GYGrab
IXInteract
BBBack, skip dialogue. Held 1 s (61 frames): reset
QLBRed portal
ERBGreen portal
ZLTRewind time
RRTForward time
SStartPause menu
KR3Marker

A button on two lines in a row is one press, held. To press twice, release it in between.

A file

# a comment
  30                    # 30 frames, nothing pressed
  20,J                  # hold Jump 20 frames
   1,J                  # a one-frame tap
   1                    # release
  10,J,G                # several buttons together
  60,M,0                # walk forward
  60,M,0,C,90           # walk and turn the camera right
Aim, 90, 10             # next line: aim yaw 90, pitch 10
  30,M,0                # walk where it now aims
***                     # fast-forward to here, then pause

Optional lines at the top: FrameRate, 60 · Seed, 0 · Level, D1 Slimebun (practice: go straight to a level). Levels: D0 Arrival · D1 Slimebun · D2 Way of Wind · D3 Face in the Rock · D4 Windmill · D5 Twisted Trail.

Sticks

MLeft stick: move. M,0 goes where the camera looks
CRight stick: camera. C,0 looks up, C,180 down
M,90Angle only: full strength
M,90,0.5Angle, then strength from 0 to 1

Full camera stick turns about 0.8° per frame. For an exact angle, use Aim.

Exact aim

Aim, 90, -20The next line starts aiming at yaw 90, pitch −20
Aim, -45.5Yaw only, pitch unchanged
YawLeft / right. Turning right adds
PitchUp / down. Positive looks down
NumbersRead them on the Aim line of Studio's info panel
SpeedUp to about 50° on the same frame. A bigger turn takes a few frames by itself
…, smoothThe view slides onto the angle (about 15 frames)

Frame by frame (²)

1Pause on a frame, click the game window, press ²
2Hold your usual game keys and move the mouse. Time stays frozen
3Wheel click: the frame is written into the file and played. Held: frames play at 25 %
4Wheel up: live recording at 5 %, from this frame
5² or F12 to leave

A frame played over an existing one replaces it. The rest of the file stays.

Live recording (F12)

F12The game stops on this frame and waits. Click the game window, press a game key: it starts
WheelSpeed: 100 / 50 / 25 / 10 / 5 %. One notch below 5 %: frame by frame
F5Half a second back. Shift+F5: one frame back
F3Stop the clock. A game key starts it again
F12 or ²End the recording

Your file is copied to backups at every start, and every take is kept in takes.

Search (F11) — experimental

By pointsF1 on the starting frame, walk, Shift+F11 at checkpoints, F11 at the end
By linesSelect lines in Studio, then F11 with Studio in front
StopF11 or F1
ResultReplayed cleanly, then written. Your file is copied to backups first
OptionsA line at the top of the file: Search, radius 1, nojump

Savestates

AutomaticOne per frame while a TAS plays at real speed or slower
F8 / F9Remember this exact frame / forget it
EditsAn edit before the saved frame drops it. Edits after it keep it
LostWhen the level changes or the game closes
Final checkPlay a finished run once from New Game: F2

Good to know

Test one partPut *** just before it, then F1
During a TASYour mouse and keyboard are off in the game
Start dialogueIt is part of the TAS: skip it with B
Info panelStudio shows position, speed, ground, yaw and pitch
LiveSplitOpen it, set Compare Against > Game Time. It follows the TAS
Field of viewA file made with another field of view can replay differently
